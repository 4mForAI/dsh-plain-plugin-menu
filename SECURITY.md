# Security Policy

## Reporting a vulnerability

Please do not disclose security vulnerabilities in public issues.

Use GitHub's **Security** tab and choose **Report a vulnerability** to send a private report to the maintainer. Include the affected version, reproduction steps, impact, and any suggested mitigation.

## Scope

`dsh-plain-plugin-menu` can ask the local DSH CLI to install or remove third-party plugins. GitHub activity, stars, licenses, and repository metadata are informational signals only; they are not a security audit or a guarantee that a plugin is safe.
